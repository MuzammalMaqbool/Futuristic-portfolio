# Azam Malik - Portfolio Website

A modern, futuristic portfolio website showcasing the work and achievements of Azam Malik - Managing Director Ejad Labs, Co-Founder Future Fest, and Digital Pakistan Movement Founder.

## 🚀 Features

- **Futuristic Design**: Cyber-themed UI with neon accents and sci-fi aesthetics
- **3D Carousel Gallery**: Interactive 3D carousel for showcasing gallery images
- **Responsive Layout**: Fully responsive design for all devices
- **Smooth Animations**: Advanced CSS animations and transitions
- **Modern Typography**: Futuristic fonts (Orbitron, Rajdhani) with Urdu support (Jameel Noori Nastaleeq)
- **Interactive Elements**: Custom cursor, scroll progress, animated counters
- **Performance Optimized**: Lazy loading, optimized assets, smooth scrolling

## 🎨 Design Highlights

- **Color Scheme**: Deep space black (#030014) with neon cyan (#00f0ff), electric purple (#a855f7), and hot pink (#f472b6)
- **Typography**: 
  - Headings: Orbitron (Futuristic geometric font)
  - Body: Rajdhani (Modern tech font)
  - Urdu: Jameel Noori Nastaleeq (Traditional Nastaleeq script)
- **Effects**: Glassmorphism, neon glows, 3D transforms, gradient animations

## 🚀 Getting Started

1. Clone the repository:
```bash
git clone https://github.com/yourusername/azam-malik-portfolio.git
cd azam-malik-portfolio
```

2. Open `index.html` in your browser or use a local server:
```bash
# Using Python
python -m http.server 8000

# Using Node.js (http-server)
npx http-server
```

3. Visit `http://localhost:8000` in your browser

## 📝 Customization

### Colors
Edit CSS variables in `styles.css`:
```css
:root {
  --accent: #00f0ff;
  --purple: #a855f7;
  --pink: #f472b6;
  --bg-primary: #030014;
}
```

### Content
- Update content in respective HTML files
- Replace images in `Assets/images/` folder
- Modify text and information as needed
